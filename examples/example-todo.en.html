Split todos into multiple lists and add tags and due dates

Adds lists, tags, due dates, due-based reminders, and a delivery log to the todo app. The storage schema changes, so the server migrates existing data to the new schema when it starts.

Broken until reloaded

Users can split todos into lists and use tags, due dates, and due-based reminders. All existing todos go into the default list.

How to check

  • Keep the old version's screen open, switch only the server to the new version, and add a todo. A red English message must appear, and after a reload the todo must be added.
  • Start the old version on a DB file that the new version has already started on once. The server must fail to start.
  • Create three todos and one reminder in the old version, then start the new version. All three must be in “Inbox” and the reminder must remain.
